# Izh Car — уличные гонки по Ижевску (прототип)

**Играть: https://vorgoron.ru/izhevsk-nfs/**

Аркадные гонки по Ижевску (застроенный город ~16 × 17 км). Город строится процедурно
из OpenStreetMap и тайлов высот Terrain Tiles, в браузере, на Three.js; вокруг игрока
подгружаются квадраты ~510 м (земля, дороги, дома, деревья, фонарные столбы, рекламные щиты, автобусные остановки, заборы), дальние выгружаются.

## Запуск

```sh
python3 tools/serve.py   # http.server с Cache-Control: no-cache
# открыть http://127.0.0.1:8765/
```

`public/city.json` уже собран. Пересобрать данные:

```sh
python3 tools/fetch_city.py              # весь город (AREA=city)
AREA=center python3 tools/fetch_city.py  # только центр — быстро, для отладки
```

Этажность многоквартирных домов без этажности в OSM и признак «частный дом» берутся из выгрузки ГИС ЖКХ
«Сведения об объектах жилищного фонда» (dom.gosuslugi.ru, открытые данные), если перед сборкой сделать
выжимку по Ижевску (`data/raw/gis_izhevsk.json`; без неё сборка идёт как раньше):

```sh
python3 tools/gis_extract.py "…/Сведения по ОЖФ Удмуртская Респ на <дата>_1.csv" "…_2.csv"
```

Сырые ответы кешируются в `data/raw/`. OSM берётся из основного API тайлами ~0.6 × 0.6 км
(Overpass часто недоступен; весь город — ~730 запросов, 40–60 минут на чистую загрузку),
рельеф — тайлы Terrarium (AWS Terrain Tiles, z13), сетка 30 м.

## Управление

Все действия и настройки собраны в меню-паузе (`Esc` или кнопка «☰ Меню»); горячие клавиши
работают и без него.

| Клавиша | Действие |
| --- | --- |
| Esc | меню / пауза |
| W A S D / стрелки | газ, тормоз/задний, руль |
| Пробел | ручник, занос |
| Shift | нитро |
| Пробел, Пробел, W (быстро, за 0,7 с) | трюк kickflip: подскок на струях выше машин и оборот в воздухе; сторона — куда рулишь; в полёте руль поворачивает боковыми соплами |
| Пробел, Пробел, S (быстро, за 0,7 с) | трюк backflip: подскок и оборот через крышу назад |
| R | вернуть на ближайшую дорогу; с пустым баком — эвакуатор до заправки |
| N | новая гонка от текущего места |
| C | камера: сзади / из салона / сверху |
| M | крупная миникарта |
| V | звук вкл/выкл |
| B | радио: Радио Адам / Даур FM / Моя Удмуртия / выкл |
| T | трафик вкл/выкл |
| G | гараж: выбор машины и цвета |
| F | во весь экран |
| мышь (тянуть) | повернуть камеру вокруг машины; на ходу через 1.5 с возвращается назад |

На телефоне (альбомная ориентация): слева — руль (коснуться и тянуть влево/вправо),
справа — газ, тормоз, ручник, нитро (ручник, ручник, газ — kickflip; ручник, ручник, тормоз — backflip); сверху — «на дорогу», полный экран (кроме iPhone) и ☰ меню (новая гонка, гараж,
звук и громкость, радио, трафик, камера, карта, полный экран — кроме iPhone). Тап по миникарте — увеличить. Свайп по свободному
месту экрана — повернуть камеру.

## Как устроено

- `tools/fetch_city.py` — OSM + DEM → `city.json` (локальные метры, x — восток, z — юг).
  Дорога сквозь дом: дом с `layer>=1` (переход между корпусами) поднимается на 4.5 м,
  в остальных прорезается арка — контур режется по коридору дороги. `tunnel=building_passage`
  и `tunnel` без `layer<0` считаются проездами, а не тоннелями.
- Мосты: `classify_bridges` (fetch_city.py) отмечает, что пересекает автомобильный мост (`cx`: водоток или
  дорога/рельсы); над водотоком `World.#carveUnderBridges` прорезает овраг вдоль русла (рельеф 30 м его
  не передаёт). Путепровод (только над дорогами/рельсами) идёт горбом (`World.#planOverpasses`): нижняя
  дорога остаётся на земле, концы при нехватке высоты приподняты, подъезды заходят на них насыпью;
  выемка под ним — только добор, если высоты всё равно не хватило. Трамвайные пути вдоль путепровода
  (между проезжими частями) идут на уровне его полотна, над пролётом — по своей плите. Полотно моста — плита, парапеты, опоры (build.js); тротуары
  вдоль моста (в OSM — отдельные пешеходные мосты) идут по его полотну.
- `public/src/chunks.js` — подгрузка квадратов вокруг игрока и тайлы миникарты.
- `public/src/world.js` — рельеф, индекс квадратов, индексы дорог и стен, маска воды (растр 2 м, дороги вырезаны —
  на мостах и плотине не тонем), граф улиц, Дейкстра. Съехал в воду — машина тонет,
  гонка начинается сначала (без гонки — на дорогу у берега).
- Частный сектор (`mark_village_houses` в `fetch_city.py`): house/detached или небольшой дом без этажности
  среди множества таких же (кроме гаражей по форме) — один этаж и двускатная крыша (стиль 6).
- `public/src/build.js` — меши: рельеф с нарисованной подложкой, дороги лентами,
  дома с процедурными окнами, деревья, фонарные столбы, рекламные щиты, остановки, заборы, миникарта.
- Заборы (`fences` в `fetch_city.py`, `buildFenceChunk` в `build.js`): `barrier=fence/wall/hedge/jersey_barrier` из OSM.
  Проёмы вырезаются при сборке: ворота и калитки (точки на линии), тропинки через забор, дороги поперёк.
  Вид — по `fence_type`/`material`, без них — по окружению: промзона и гаражи — бетонные плиты, частный сектор и СНТ —
  доски или профлист, остальное — решётка. Заборы — стены для столкновений.
- `public/src/footbridges.js` — пешеходные мосты (footway/pedestrian + bridge): плита, ажурные перила,
  колонны вне проезжей части, над дорогой просвет 5.5 м. Особые мосты (`FOOTBRIDGE_STYLE` в `fetch_city.py`):
  `level` — земля с этой стороны поднимается до настила (насыпь с подпорной стенкой, поправка
  рельефа в `World.addTerrainPatch`), `stairs` — лестница вниз с другого конца. Тоннели короче 60 м — проезды под мостом, дорога видна.
- `public/src/landmarks.js` — достопримечательности: процедурные модели по контурам
  из OSM (список и OSM id — `LANDMARKS` в `tools/fetch_city.py`).
- `public/src/vehicles.js` — машины ижевского автопрома: «Ода», Москвич-412, «Комби», «Каблучок»,
  пикап ИЖ-2715, фургон «Ода», LADA Vesta. Модель по профилю сбоку, характеристики (скорость, разгон, сцепление).
  «Ода», Москвич-412, пикап, «Каблучок» и Веста — готовые модели `public/models/*.glb` (`loadVehicleMeshes` грузит их на старте; не загрузилась —
  рисуется процедурная). Собираются `tools/models` (`oda.mjs` из STL, `moskvich.mjs`, `pickup.mjs` и `vesta.mjs` из glTF, `kabluk.mjs` — перед пикапа и будка из COLLADA через `dae2gltf.py`; общее — `lib.mjs`).
- `public/src/garage.js` — гараж: выбор машины и цвета, хранится в localStorage; смена машины перезапускает гонку.
- `public/src/car.js` — аркадная физика (боковое сцепление, ручник, нитро, отскок от стен); вне дороги
  (трава, лес, пустырь — `World.surfaceAt`) скорость ×0.45, разгон ×0.5, хуже сцепление, тряска и пыль.
- `public/src/audio.js` — звук синтезом Web Audio: мотор с передачами, шины, ветер, нитро, удары, сигналы гонки; трафик вокруг — моторы ближайших машин (панорама, Доплер), шорох шин потока, гудки.
- `public/src/radio.js` — радио: интернет-потоки (Радио Адам, Даур FM, Моя Удмуртия) через `<audio>`, переключение по кругу.
- `public/src/traffic.js` — трафик: ~50 машин и автобусов по графу улиц вокруг игрока (правая полоса,
  односторонние, торможение перед впереди идущими, столкновения: удар по массам с закруткой, сбитые машины скользят, бьются о стены и друг о друга и возвращаются в полосу); одна InstancedMesh на тип.
- `public/src/signals.js` — светофоры из OSM (`highway=traffic_signals`): узлы ближе 35 м — один перекрёсток
  с двумя фазами по осям; трафик стоит на красный.
- `public/src/touch.js` — сенсорное управление (включается на устройствах с сенсорным экраном).
- `public/src/sky.js` — небо-купол с градиентом и низкополигональные облака, которые несёт ветром.
- `public/src/fuel.js` — заправки из OSM (`amenity=fuel`): колонки под навесом, стела; бак тратится по пробегу
  (нитро ×3, у моделей свой расход), на АЗС стоя — заправка; пустой бак — эвакуатор (R).
- `public/src/queues.js` — очереди на заправках: 26 машин от колонки через въезд вдоль обочины ближайшей улицы
  (по её изгибам); раз в 10–20 с голова уезжает, очередь подтягивается.
- `public/src/effects.js` — нитро: пламя из выхлопа, искры, «линии скорости»; камера отстаёт при разгоне (main.js).
- Трамвайные пути (`align_tram_tracks` в fetch_city.py): пути двухпутной линии ставятся на ±1.6 м от
  середины между ними (в OSM нарисованы независимо и «гуляют»); у развилок — как в OSM.
- `public/src/trams.js` — трамваи по маршрутам OSM (route=tram, 11 номеров): весь парк ~60 вагонов (раз в ~4 км на направление) движется
  всегда, рисуются ближние; остановки, обратный рейс на конечной, номер на табло, звонок перед игроком.
- `public/src/race.js` — маршрут 1.3–2.3 км по главным улицам, чекпоинты каждые ~230 м.
- `public/src/net.js` — мультиплеер через Firebase Realtime Database (проект `izh-car`, конфиг в
  `public/src/firebase-config.js`, правила в `database.rules.json`, заливка — `firebase deploy --only database`):
  в общем городе пока без сети (лимиты Firebase), `?room=…` — своя комната с другими игроками; чужие машины с никами; столкновения каждый считает для своей машины сам.
  В комнате «Новая гонка» (N) — общая: старт у запустившего, финиш случайный, всех ставит в стартовую
  сетку, отсчёт по часам сервера, после финиша — таблица мест (`rooms/<комната>/race`).
  `public/net-test.html?room=…` — проверка связи без игры.
