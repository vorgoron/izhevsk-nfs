# Izh Car — уличные гонки по Ижевску (прототип)

**Играть: https://izh-car.web.app** (копия на GitHub Pages — https://vorgoron.ru/izhevsk-nfs/)

Аркадные гонки по Ижевску (застроенный город ~16 × 17 км). Город строится процедурно
из OpenStreetMap и тайлов высот Terrain Tiles, в браузере, на Three.js; вокруг игрока
подгружаются квадраты ~510 м (земля, дороги, дома, деревья, фонарные столбы, рекламные щиты, автобусные остановки, вывески магазинов на фасадах, заборы,
разметка и знаки, шлагбаумы, трубы, вышки, ЛЭП), дальние выгружаются.

## Запуск

```sh
python3 tools/serve.py   # http.server с Cache-Control: no-cache
# открыть http://127.0.0.1:8765/
```

`public/city.json` уже собран. Пересобрать данные:

```sh
python3 tools/fetch_city.py              # весь город (AREA=city)
AREA=center python3 tools/fetch_city.py  # только центр — быстро, для отладки
```

Этажность многоквартирных домов без этажности в OSM и признак «частный дом» берутся из выгрузки ГИС ЖКХ
«Сведения об объектах жилищного фонда» (dom.gosuslugi.ru, открытые данные), если перед сборкой сделать
выжимку по Ижевску (`data/raw/gis_izhevsk.json`; без неё сборка идёт как раньше):

```sh
python3 tools/gis_extract.py "…/Сведения по ОЖФ Удмуртская Респ на <дата>_1.csv" "…_2.csv"
```

Камеры скорости и перекрёстков — из перечня комплексов Госавтоинспекции Удмуртии (.xls с сайта ГАИ, адреса и координаты).
Новый перечень обновляет `data/gibdd_cams.json` и сразу `cams` в `public/city.json`, без пересборки города
(нужен `pip install xlrd`); `fetch_city.py` при сборке берёт камеры из того же `data/gibdd_cams.json`:

```sh
python3 tools/gibdd_cams.py "…/Kompleksy_dlya_sayta_Gosavtoinspekcii_<год>.xls"
```

Вывески магазинов (`shops`) садятся на стену, ближнюю к месту из OSM, с поправкой на улицу перед стеной (дворовые
проезды `service` улицей не считаются — иначе вывески уходили во двор). Пересадить вывески в готовом `city.json` после
правки правил (`shop_signs` в `fetch_city.py`), без OSM и пересборки:

```sh
python3 tools/shop_walls.py
```

Автобусы трафика ездят только по своим маршрутам — `buses` в `city.json` (отношения `route=bus` из OSM, цепочки
узлов дорог; маршрут кончился — на другой через тот же узел), троллейбусы — по своим (`trolleys`, `route=trolleybus`),
над ними — контактная сеть: пара проводов над правой полосой и опоры с растяжками (`wires.js`, ячейками по 600 м). На стройках — башенные краны (`cranes`: у строящегося
дома `building=construction`, по одному на стройку, стрела — на дом; голые площадки `landuse=construction` в OSM часто
остаются после стройки — их не берём).
Аварийные и ветхие дома по ГИС ЖКХ (поле `st` выжимки, флаг `ru` у дома) — облезлые: серые стены с пятнами
штукатурки до кирпича и потёками, часть окон заколочена или выбита, ночью горят редко (`aRuin` в шейдере фасада).
Дописать маршруты, краны и флаги домов в готовый `city.json` из кеша OSM, без пересборки:

```sh
python3 tools/patch_city.py          # buses, trolleys и cranes
python3 tools/patch_city.py cranes   # только краны
```

Сырые ответы кешируются в `data/raw/`. OSM берётся из основного API тайлами ~0.6 × 0.6 км
(Overpass часто недоступен; весь город — ~730 запросов, 40–60 минут на чистую загрузку),
рельеф — тайлы Terrarium (AWS Terrain Tiles, z13), сетка 30 м.

## Управление

Все действия и настройки собраны в меню-паузе (`Esc` или кнопка «☰ Меню»); горячие клавиши
работают и без него.

| Клавиша | Действие |
| --- | --- |
| Esc | меню / пауза |
| W A S D / стрелки | газ, тормоз/задний, руль |
| Пробел | ручник: тормозит задними колёсами и срывает зад в занос; под газом занос держится — дрифт: руль в поворот — круче угол (до 45°), прямо — ~25°, против — выход из заноса; без газа занос гаснет. Тормоз с рулём до упора на скорости тоже чуть срывает зад. На грунте скользче: занос шире и дольше, сорвать зад можно одним газом с рулём до упора, долгий контрруль под газом перекладывает занос в другую сторону. Задние колёса оставляют следы: на асфальте чёрные, на грунте бурые; на асфальте из-под них валит дым, на грунте — пыль |
| Shift | нитро, если куплено в автосалоне (баллон сам наполняется за ~17 с; на АЗС или в меню — сразу, за деньги) |
| Пробел, Пробел, W (быстро, за 0,7 с) | трюки — только с системой «Кузнечик» из автосалона; трюк kickflip: подскок на струях выше машин и оборот в воздухе; сторона — куда рулишь; в полёте руль поворачивает боковыми соплами |
| Пробел, Пробел, S (быстро, за 0,7 с) | трюк backflip: подскок и оборот через крышу назад |
| Пробел, Пробел, A / D (быстро, за 0,7 с) | трюк «бочка»: подскок и оборот влево / вправо, машину сносит вбок (на телефоне пока нет) |
| — | после трюка можно сесть на крышу машины, автобуса, трамвая или невысокого дома (за это — сверху денег); машина и трамвай везут, съехал с края — падаешь |
| R | вернуть на ближайшую дорогу; с пустым баком — эвакуатор до заправки |
| N | новая гонка от текущего места: выбор длины (1 — ~2 км, 2 — ~4 км, 3 — ~7 км), N ещё раз — длина как в прошлый раз. В гонке трафика втрое меньше; в гонке с друзьями — только трафик вдоль маршрута «по расписанию», у всех одинаковый |
| J | такси: заказ — пассажир ждёт на остановке рядом (маршрут навигатора, жёлтый столб света у места), остановиться у столба — сел; отвезти по адресу и остановиться — плата: 1 000 ₽ + 1 800 ₽ за км маршрута, быстрее 45 км/ч в среднем — +30 %, каждый удар — −15 % (не меньше 30 %); J ещё раз — отменить; гонка отменяет заказ |
| C | камера: сзади / из салона / сверху / кино (сама меняет планы — для роликов; вместе с `?nohud`) |
| Y | время суток: авто (как сейчас в Ижевске) / день / ночь; ночью горят фары, фонари и окна домов |
| M | карта города: заправки, достопримечательности, камеры; нажать на место — маршрут туда (синие стрелки на дороге); Ctrl (на Mac и Cmd) + нажатие — перенести машину на ближайшую дорогу (для отладки) |
| V | звук вкл/выкл |
| B | радио: следующая станция (Радио Адам / Даур FM / Моя Удмуртия / Наше Радио / Радио Максимум / выкл); выбрать барабаном — нажать на надпись радио или в меню |
| T | трафик вкл/выкл |
| G | гараж — автосалон: машины, цвет, детали, улучшения (двигатель, шины, нитро, «Кузнечик», у «Оды» — 4×4); ←→ машина, ↑↓ цвет |
| F | во весь экран |
| I | отладка: координаты машины, камера, улица и трамвайный путь под машиной — для скриншотов (`?debug` в адресе — сразу включена) |
| мышь (тянуть) | повернуть камеру вокруг машины; на ходу через 1.5 с возвращается назад; в гараже — крутить облёт |
| колесо мыши | камера сзади ближе/дальше (запоминается); в гараже — облёт ближе/дальше |

На телефоне (альбомная ориентация): слева — руль (коснуться и тянуть влево/вправо),
справа — газ, тормоз, ручник, нитро (нитро — переключатель: касание взводит, горит под газом, гаснет от касания, тормоза или пустого баллона; ручник, ручник, газ — kickflip; ручник, ручник, тормоз — backflip); сверху — «на дорогу», 🎥 камера, полный экран (кроме iPhone) и ☰ меню (новая гонка, гараж,
звук и громкость, радио, трафик, камера, карта города, полный экран — кроме iPhone). Тап по миникарте — карта города. Свайп по свободному
месту экрана — повернуть камеру, щипок двумя пальцами — камера ближе/дальше.

## Как устроено

- `tools/fetch_city.py` — OSM + DEM → `city.json` (локальные метры, x — восток, z — юг).
  Дорога сквозь дом: дом с `layer>=1` (переход между корпусами) поднимается на 4.5 м,
  в остальных прорезается арка — контур режется по коридору дороги. `tunnel=building_passage`
  и `tunnel` без `layer<0` считаются проездами, а не тоннелями.
- Мосты: `classify_bridges` (fetch_city.py) отмечает, что пересекает автомобильный мост (`cx`: водоток или
  дорога/рельсы); над водотоком `World.#carveUnderBridges` прорезает овраг вдоль русла (рельеф 30 м его
  не передаёт). Путепровод (только над дорогами/рельсами) идёт горбом (`World.#planOverpasses`): нижняя
  дорога остаётся на земле, концы при нехватке высоты приподняты, подъезды заходят на них насыпью;
  выемка под ним — только добор, если высоты всё равно не хватило. Трамвайные пути вдоль путепровода
  (между проезжими частями) идут на уровне его полотна, над пролётом — по своей плите. Полотно моста — плита, парапеты, опоры (build.js); тротуары
  вдоль моста (в OSM — отдельные пешеходные мосты) идут по его полотну.
- Язык интерфейса — русский или удмуртский (`public/src/i18n.js`, черновик перевода): переключатель на заставке и в меню
  «Настройки → Язык», помнится в `localStorage.lang`. Код пишет строки по-русски; при удмуртском словарь `WORDS`
  (и шаблоны `PATTERNS` для строк с числами) переводит текстовые узлы и подсказки поверх DOM, новые — через
  `MutationObserver`. Новая строка интерфейса — добавить её в `WORDS`, иначе останется русской. Не переводятся
  названия улиц, мест, станций и машин и текст на холстах (щиты, карта, тахометр).
- `public/src/chunks.js` — подгрузка квадратов вокруг игрока и тайлы миникарты.
- `public/src/world.js` — рельеф, индекс квадратов, индексы дорог и стен, маска воды (растр 2 м, дороги вырезаны —
  на мостах и плотине не тонем), граф улиц, Дейкстра. Съехал в воду — машина тонет,
  гонка начинается сначала (без гонки — на дорогу у берега).
- Тротуары и дорожки (`walks.js`, меш — `buildWalkChunk` в `build.js`) — геометрией, а не на текстуре земли: плитка
  ровная поперёк, по длине — по рельефу, с бордюрами и боками до земли. Из OSM — footway, steps (тропы
  path/track остаются полосой на текстуре); тротуары OSM впритык вдоль друг друга — один, пошире; cycleway —
  асфальт с белыми краями и значком велосипеда раз в 40 м, тротуар рядом сужается до неё; вдоль улиц primary…residential, где своего тротуара в OSM нет, — придуманный
  (`SIDEWALK` в `world.js`, на крупных — с газоном). Пересечения дорожек — одной площадкой (плитка по сетке города, общая высота, без
  бордюров внутри). Переходы (`footway=crossing`) тротуаром не строятся; обрезки у перекрёстков (придуманные короче
  25 м между дорогами или 15 м, OSM короче 8 м) убираются. Плита обрывается на проезжей части (краем уходит под асфальт —
  дорога выше), на путях и в домах; к дороге не поднимается. По ней едут (`World.ground`, `surfaceAt` → 'paved'); деревья, столбы и
  щиты на неё не ставятся. Дальше `WALK_FAR` (`chunks.js`) меш прячется, остаётся узкая полоса на текстуре.
- Частный сектор (`mark_village_houses` в `fetch_city.py`): house/detached или небольшой дом без этажности
  среди множества таких же (кроме гаражей по форме) — один этаж и двускатная крыша (стиль 6).
- `public/src/build.js` — меши: рельеф с нарисованной подложкой, дороги лентами,
  дома с процедурными окнами, деревья, фонарные столбы, рекламные щиты, остановки, заборы, миникарта.
  Вывески магазинов, банков, аптек, кафе и контор (`shops.js`, из `city.json` → `shops`) — только у ближних квадратов.
- Заборы (`fences` в `fetch_city.py`, `buildFenceChunk` в `build.js`): `barrier=fence/wall/hedge/jersey_barrier` из OSM.
  Проёмы вырезаются при сборке: ворота и калитки (точки на линии), тропинки через забор, дороги поперёк.
  Заборы на пешеходных мостах (перила по краю настила) и с `layer` ≥ 1 не берутся — на земле они встали бы поперёк улицы.
  Вид — по `fence_type`/`material`, без них — по окружению: промзона и гаражи — бетонные плиты, частный сектор и СНТ —
  доски или профлист, остальное — решётка. Плиты, кирпич и блоки — стены для столкновений; живая изгородь
  проезжается насквозь; решётку, рабицу, доски и профлист машина сносит кусками (`SOFT_FENCES` в `world.js`, см. `breakables.js`).
- `public/src/footbridges.js` — пешеходные мосты (footway/pedestrian + bridge): плита, ажурные перила,
  колонны вне проезжей части, над дорогой просвет 5.5 м. Особые мосты (`FOOTBRIDGE_STYLE` в `fetch_city.py`):
  `level` — земля с этой стороны поднимается до настила (насыпь с подпорной стенкой, поправка
  рельефа в `World.addTerrainPatch`), `stairs` — лестница вниз с другого конца. Тоннели короче 60 м — проезды под мостом, дорога видна.
- `public/src/props.js` — мелочи из OSM (точки готовит `World.#initPoints`, данные — `road_points`, `tall_things`, `playgrounds`
  в `fetch_city.py`): «зебры» на размеченных переходах (`highway=crossing`) и знаки 5.19; лежачие полицейские
  (`traffic_calming=bump/hump/table`) — широкий асфальтовый горб (~3 м) с белыми квадратами шахматкой, полотно поднимается (`World.bumpAt` в `ground`), на скорости
  больше ~32 км/ч машину подбрасывает (`Car.#bump`; на 60 км/ч — на ~0,7 м, на 90 — на ~1,2 м), трафик перед ними сбрасывает скорость (`World.bumpAhead`), знаки 5.20;
  «Уступи дорогу» и STOP (`highway=give_way/stop`, по `direction`, без него — для едущих к ближайшему перекрёстку; трафик у STOP
  встаёт на секунду, у «Уступи» сбавляет ход, дальше пропускает едущих по поперечной улице — `World.yieldAhead`; игроку за STOP
  без остановки — штраф 500 ₽, `yields.js`, без камеры); «Андреевский
  крест» у ж/д переездов (`railway=level_crossing`); шлагбаумы на дорогах (`barrier=lift_gate`), столбики (`bollard`) и бетонные
  блоки (`block`); детские площадки (`leisure=playground`: песок и горка с качелями). Знаки, шлагбаумы, столбики и площадки
  сносятся (`breakables.js`). Высокое (`towers`): трубы, мачты связи и освещения, водонапорные и прочие башни, башенные краны,
  опоры и столбы ЛЭП — модели по виду, высота из `height` или своя; стены у основания (у опор ЛЭП — четыре ноги); провода
  (`power=line/minor_line`) — от траверсы к траверсе с провисом. Ночью горят прожекторы мачт и красные огни на трубах и вышках.
- Грунтовки (`surface=unpaved/ground/gravel/…` → `sf` у дороги): своя текстура с колеями, `World.surfaceAt` → `'dirt'`, в `car.js`
  — бездорожье на 60 % (`DIRT_OFF`: пыль, бурые следы и срыв газом в занос — как на грунте). Ряды деревьев (`natural=tree_row`) — деревья через 7 м. Цвет стен и крыш —
  `building:colour`/`roof:colour` (`bc`/`rc`), если размечены. На большой карте — названия парков, площадей и прудов (`labels`).
- `public/src/police.js` — ГИБДД: на каждой второй камере скорости в 35 м за ней у обочины стоит пост ДПС (белая Веста с синей
  полосой и мигалкой). Мимо поста быстрее предела на 20 км/ч, удар в патрульную или (в 35 % случаев) штраф камеры — погоня: мигалка,
  сирена (`Sound.siren`), патрульная едет к игроку кратчайшим путём по улицам (`World.shortestPath`, односторонние ей не указ), ближе
  50 м — прямо на него, перед ним тормозит; через 25 с выезжает вторая (сзади, в 170 м). Стоишь рядом с патрульной медленнее 4 м/с
  2,5 с — задержание, штраф 5 000 ₽; дальше 320 м от всех патрульных 8 с — ушёл, +1 500 ₽. В гонке и в гараже погони нет,
  перенос машины её отменяет. Сквозь трафик патрульные пока проезжают.
- `public/src/parkings.js` — открытые парковки (`amenity=parking`, кроме многоэтажных и подземных; `parkings` в `city.json`,
  `parking_lots` в `fetch_city.py`): места 2,6 × 5 м рядами вдоль длинной стороны участка, ряд — проезд 6 м — два ряда спинами;
  место не ставится на дорогу, проезд парковки из OSM и в дом, на наш тротуар — отсекается в игре. Асфальт — на текстуре земли
  (`build.js`), белая разметка — мешем у парковок ближе 260 м, на ~55 % мест стоят машины (ближайшие 40, одни и те же у всех).
  Дописать в готовый `city.json`: `python3 tools/patch_city.py parkings`.
- `public/src/landmarks.js` — достопримечательности: процедурные модели по контурам
  из OSM (список и OSM id — `LANDMARKS` в `tools/fetch_city.py`).
- `public/src/vehicles.js` — машины ижевского автопрома: «Ода», Москвич-412, «Комби», «Каблучок»,
  пикап ИЖ-2715, LADA Vesta (фургон «Ода» отключён — нет хорошей модели, `ODAVAN`). Модель по профилю сбоку, характеристики (скорость, разгон, сцепление).

  трамплины у всех на одних местах, канистры берёт каждый свои; отставшему от лидера нитро наполняется до двух раз
  быстрее. **Перед выкладкой** — `firebase deploy --only database` (поля `race.w`, `race.l`).
  `public/net-test.html?room=…` — проверка связи без игры.
  Экран «Поехали» даёт выбор: «Исследовать город» (один) или «Играть с друзьями» — своя комната, ссылка на неё уходит
  в «Поделиться» на телефоне или в буфер обмена; открывший ссылку видит «Поехали к друзьям» или «Ездить одному».

Идеи на будущее — что ещё взять из OSM и как зарабатывать: [`docs/ideas.md`](docs/ideas.md).

## Публикация

GitHub Pages через Actions: `.github/workflows/pages.yml` выкладывает `public/` при каждом пуше в `main`.

Firebase Hosting (https://izh-car.web.app) — вручную, `firebase deploy --only hosting` (выкладывает `public/` как
есть на диске, вместе с незакоммиченным). Всё отдаётся с `Cache-Control: no-cache`: файлы без хешей в именах,
браузер каждый раз сверяет ETag и не берёт старые модули из кэша.
