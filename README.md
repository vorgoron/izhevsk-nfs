# Ижевск: уличные гонки (прототип)

**Играть: https://vorgoron.ru/izhevsk-nfs/**

Аркадные гонки по центру Ижевска (~3.6 × 3 км: пруд, плотина, Центральная площадь,
Карла Маркса, Пушкинская, Удмуртская). Город строится процедурно из OpenStreetMap
и рельефа Copernicus DEM, в браузере, на Three.js.

## Запуск

```sh
python3 tools/serve.py   # http.server с Cache-Control: no-cache
# открыть http://127.0.0.1:8765/
```

`public/city.json` уже собран. Пересобрать данные (например, сдвинуть область —
константы `SOUTH/NORTH/WEST/EAST` в скрипте):

```sh
python3 tools/fetch_city.py
```

Сырые ответы кешируются в `data/raw/`. OSM берётся из основного API тайлами
(Overpass часто недоступен), рельеф — Open-Meteo Elevation API (лимит 600 точек
в минуту, поэтому скрипт делает паузы, ~6 минут на чистую загрузку).

## Управление

| Клавиша | Действие |
| --- | --- |
| W A S D / стрелки | газ, тормоз/задний, руль |
| Пробел | ручник, занос |
| Shift | нитро |
| R | вернуть на ближайшую дорогу |
| N | новая гонка от текущего места |
| C | камера: сзади / из салона / сверху |
| M | крупная миникарта |
| V | звук вкл/выкл |
| T | трафик вкл/выкл |

На телефоне (альбомная ориентация): слева — руль (коснуться и тянуть влево/вправо),
справа — газ, тормоз, ручник, нитро; сверху — камера, карта, новая гонка, на дорогу,
трафик, звук, полный экран (кроме iPhone). Тап по миникарте — увеличить.

## Как устроено

- `tools/fetch_city.py` — OSM + DEM → `city.json` (локальные метры, x — восток, z — юг).
  Дорога сквозь дом: дом с `layer>=1` (переход между корпусами) поднимается на 4.5 м,
  в остальных прорезается арка — контур режется по коридору дороги. `tunnel=building_passage`
  и `tunnel` без `layer<0` считаются проездами, а не тоннелями.
- `public/src/world.js` — рельеф, индексы дорог и стен, граф улиц, Дейкстра.
- `public/src/build.js` — меши: рельеф с нарисованной подложкой, дороги лентами,
  дома с процедурными окнами, деревья, миникарта.
- `public/src/footbridges.js` — пешеходные мосты (footway/pedestrian + bridge): плита, ажурные перила,
  колонны вне проезжей части, над дорогой просвет 5.5 м. Тоннели короче 60 м — проезды под мостом, дорога видна.
- `public/src/landmarks.js` — достопримечательности: процедурные модели по контурам
  из OSM (список и OSM id — `LANDMARKS` в `tools/fetch_city.py`).
- `public/src/car.js` — аркадная физика (боковое сцепление, ручник, нитро, отскок от стен).
- `public/src/audio.js` — звук синтезом Web Audio: мотор с передачами, шины, ветер, нитро, удары, сигналы гонки.
- `public/src/traffic.js` — трафик: ~50 машин и автобусов по графу улиц вокруг игрока (правая полоса,
  односторонние, торможение перед впереди идущими, столкновения с игроком); одна InstancedMesh на тип.
- `public/src/signals.js` — светофоры из OSM (`highway=traffic_signals`): узлы ближе 35 м — один перекрёсток
  с двумя фазами по осям; трафик стоит на красный.
- `public/src/touch.js` — сенсорное управление (включается на устройствах с сенсорным экраном).
- `public/src/race.js` — маршрут 1.3–2.3 км по главным улицам, чекпоинты каждые ~230 м.
